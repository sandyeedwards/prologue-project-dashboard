# Step 9 v1.0.8 — Executive dashboard and navigation refinement

This release turns the home dashboard into a single filterable portfolio report and reduces the persistent navigation to the four activities most employees need: Dashboard, Projects, Compare, and Help.

## Portfolio dashboard

The dashboard accepts the same search, health, status, type, financial-coverage, and sort filters as the Projects page. The selected scope is applied consistently to:

- KPI totals;
- financial and hours graphs;
- health distribution;
- attention cards;
- the project table.

## Health display

Health color remains available as an urgency cue, but the pill now displays the exact health percentage. The band name remains in accessible labels and hover text.

## Help and administration

The Help page explains health, provisional financials, data-quality corrections, and the recommended reporting workflow. Labor, Users, Calculations, and Teamwork connection tools are presented there only to users whose role permits access.
