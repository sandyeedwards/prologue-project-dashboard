# Step 10 v1.1.10 — Historical Range Interaction

## Scope

This release changes only the Historical Revenue & Net Profit chart interaction and labels. Financial calculations, source metrics, Teamwork synchronization, database schema, API routes, and report filters remain unchanged.

## Two-click zoom

1. Hover within the plot and click once to set the first date boundary.
2. Move left or right to preview the range.
3. Click again to apply the zoom.
4. The selected range becomes the active Custom range.
5. Press Escape to cancel an unfinished selection.

## Custom range

The new Custom tab opens From and Through calendar inputs when no custom range exists. Existing custom ranges are retained when switching temporarily to another preset. Clicking an already active Custom tab reopens the date editor.

## Labels

The legend and tooltip no longer repeat the word “Cumulative” for every line. The underlying series remain cumulative.
