# Step 9 v1.0.7 — group cost performance and issue evidence

## Operational groups

Each operational group or DataHall area is a native HTML disclosure panel. Groups are closed by default and expose their calculated task branches only when opened. Search and coverage filters automatically open the matching groups and do not change whole-project financial results.

## Cost performance

Group revenue is not allocated, so the application does not infer group profit or margin. The cost-performance graph compares actual cost and costed remaining work with the Teamwork task-list target cost. Missing task-list targets remain missing.

## Data-quality evidence

Quality issues can include source evidence and correction links. UNALLOCATED_PROJECT_TIME lists the actual project-only time entries with user, date, description, hours, and historical labor cost. Other supported issues show affected time entries, tasks, or task lists. Links open the relevant Teamwork project Time, task, or Finance area.
