# Step 9 v1.0.14

## Date filter rule

A project is included when its known project date interval overlaps the requested interval. If a date filter is active and a project has neither a start nor end date, it is omitted.

## Combined operational groups

Ready Set and DataHall projects receive dedicated combined buckets. Standard task lists roll into Fieldwork, Mobilization, Modeling, or Other.

## Revenue allocation

Operational-group revenue is an analytical presentation allocation only. Each project fee is allocated by complete task-list target cost when available. If target coverage is incomplete, estimated hours are used. If estimates are unavailable, forecast cost is used. Equal share is the final fallback.

The allocation does not change project-level financials or write anything to Teamwork.

## Chart arithmetic

The full bar is allocated revenue. The darker blue portion is included forecast cost. The green portion is forecast profit. The lighter cost bar below the zero line repeats forecast cost solely to communicate subtraction and is not included again in any calculation.
